Signalform Studio

A creative web studio concept where each interaction has a clear job to do, built with React 19, Vite, and the React Bits SpotlightCard.

View live site

Project overview

Signalform Studio is a self-initiated concept for testing a studio site that feels composed while still reacting to each person’s input. Its hero artwork is an original project asset, and the interface is shaped so visitors can understand the offer and choose a focus without being buried in a long pitch.

React 19React BitsViteStatic build

The 30-second version

  • React 19 composes the hero, capability cards, and selected-focus state
  • Vite produces a static build served directly from GitHub Pages at /signalform-studio/
  • The React Bits SpotlightCard is adapted locally so light follows the visitor’s pointer
  • Lightweight CSS transitions include an operating-system reduced-motion fallback
  • The cobalt ribbon sculpture is an original asset made for this project
  • The 375px viewport was checked for horizontal overflow

Who this project fits

It fits studios, digital brands, and service businesses whose website needs to build confidence as much as share information. This structure makes sense when you have a point of view and want visitors to feel it through hierarchy, pacing, and purposeful interaction.

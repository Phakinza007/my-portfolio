# Lean Code Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove the duplication that has to be maintained by hand — 10 thumbnails repeated across 4 files, behaviour scripts repeated across 12, search markup repeated across 61 — without introducing a build step and without changing anything a visitor sees.

**Architecture:** Thumbnails are transcribed from browser-measured geometry into standalone SVG files. Behaviour scripts collapse into one `assets/site-ui.js` with self-guarding blocks. Search markup collapses to a one-line placeholder that the existing `site-search.js` fills.

**Tech Stack:** Plain HTML, CSS and vanilla JS. No framework, no build step, no new dependencies.

**Source spec:** `docs/superpowers/specs/2026-08-06-lean-code-design.md`

## The extractor is already prototyped

The riskiest part of this plan — D2's geometry transcription — was built and run against a real card before this plan was written. Findings that shaped it:

1. **Measure at the card's natural rendered size, not a forced 1200×750.** The mini-UIs size text in `rem`, which does not scale when you force the container wider. Forcing 1200px produced 6.7px text in a 750px-tall image. The `viewBox` takes the natural box (`351.3 × 219.6` for Iron Republic) and the SVG scales from there.
2. **A side-by-side comparison must also happen at natural size.** Comparing at a forced width makes the SVG look wrong when it is right, because the SVG scales and the `rem` text does not. This produced a false alarm during prototyping.
3. **The extractor handles fills, borders, radii, text and linear gradients. It does not handle `opacity`, `repeating-linear-gradient`, `mix-blend-mode`, `transform` or `box-shadow`.** On Iron Republic that meant one `opacity: 0.07` watermark rendered at full strength and one scanline overlay disappeared. Task 1 adds `opacity`; the rest are audited per card and patched by hand.

Iron Republic transcribed to **3.0 KB** of SVG against **4.2 KB** of inline markup, with the gradient converted to a 4-stop `<linearGradient>`.

## Global Constraints

- **No build step.** No `npm install`, no generated output, no new Actions workflow.
- **Zero visible difference.** This is a refactor. A passing Lighthouse score is not evidence the page still looks right — `work.html` once shipped with all 13 cards at `opacity: 0` and passed every automated check. Every card gets a human visual comparison.
- **Nav markup stays in HTML.** The internal link graph is what the industry pages rank on.
- **Card text stays in HTML.** Only the thumbnail moves out.
- **Demo pages are out of scope entirely.** `DRIP`, `MuseRoom`, `ElevateCommerce`, `dental-clinic`, `spa-retreat`, `construction-landing`, `sorn-restaurant`, `lumi-clinic`, `BookEase` carry their own inline reveal scripts. Those are simulated client sites, not duplication. Do not touch them.
- **Quality bars:** Lighthouse mobile Accessibility 100, SEO 100, CLS 0. Best Practices caps at 77 sitewide (Clarity third-party cookies). `404.html` caps at SEO 66 (`noindex`, correct for a 404).
- **No overflow at 375×812.** `resize_window` silently does nothing in this environment — use the iframe recipe and confirm `clientWidth === 375` before believing a result.
- **SVG files match the existing house style** — see `assets/thumbs/construction-landing.svg`: `role="img"`, `aria-labelledby`, a `<title>` and a `<desc>`.
- **`main` auto-deploys.** Every commit must leave the site shippable.

- [ ] **Step 2: Paste the extractor into the console**

```js
window.__thumbToSvg = function (cardIndex) {
  const thumb = [...document.querySelectorAll('.work-card[data-industry] .work-thumb')][cardIndex];
  if (!thumb || thumb.querySelector('img')) return { error: 'not a div thumb' };

  // Measure at the natural rendered size. The mini-UIs size text in rem, which
  // does NOT scale if you force the container wider — forcing 1200px yields
  // 6.7px text in a 750px-tall image. viewBox takes the natural box instead.
  const base = thumb.getBoundingClientRect();
  const W = +base.width.toFixed(1), H = +base.height.toFixed(1);
  const shapes = [];
  const px = v => Math.round(parseFloat(v) || 0);

  thumb.querySelectorAll('*').forEach(el => {
    const cs = getComputedStyle(el);
    if (cs.display === 'none' || cs.visibility === 'hidden' || +cs.opacity === 0) return;
    const r = el.getBoundingClientRect();
    if (r.width < 0.5 || r.height < 0.5) return;
    const x = +(r.left - base.left).toFixed(1), y = +(r.top - base.top).toFixed(1);
    const w = +r.width.toFixed(1), h = +r.height.toFixed(1);
    const op = +cs.opacity < 1 ? +cs.opacity : null;
    const bg = cs.backgroundImage !== 'none' ? cs.backgroundImage : cs.backgroundColor;
    const hasFill = bg && bg !== 'rgba(0, 0, 0, 0)';
    const bw = px(cs.borderTopWidth);
    if (hasFill || bw) shapes.push({ t:'rect', x, y, w, h, fill: bg, r: px(cs.borderTopLeftRadius),
                                     stroke: bw ? cs.borderTopColor : null, sw: bw, op });
    const txt = [...el.childNodes].filter(n => n.nodeType === 3)
                                  .map(n => n.textContent.trim()).join(' ').trim();
    if (txt) shapes.push({ t:'text', x, y: +(y + parseFloat(cs.fontSize) * 0.8).toFixed(1),
                           s: txt, fill: cs.color, fs: +parseFloat(cs.fontSize).toFixed(2),
                           fw: cs.fontWeight, op });
  });
  return { W, H, shapes };
};
```

`opacity` is captured because the prototype missed it: Iron Republic's `0.07` watermark rendered at full strength without it.

- [ ] **Step 3: Paste the serialiser**

```js
window.__svgFrom = function (data, title, desc) {
  const esc = s => String(s).replace(/[&<>"]/g, c => ({'&':'&amp;','<':'&lt;','>':'&gt;','"':'&quot;'}[c]));
  let defs = '', gi = 0;
  const fillOf = s => {
    const f = String(s.fill);
    if (!f.includes('gradient')) return f;
    const inner = f.slice(f.indexOf('(') + 1, f.lastIndexOf(')'));
    const parts = inner.split(/,(?![^(]*\))/).map(x => x.trim());
    let angle = 180;
    if (/^-?[\d.]+deg$/.test(parts[0])) angle = parseFloat(parts.shift());
    else if (/^to /.test(parts[0])) { const d = parts.shift();
      angle = /right/.test(d) ? 90 : /left/.test(d) ? 270 : /top/.test(d) ? 0 : 180; }
    const rad = (angle - 90) * Math.PI / 180;
    const x1 = (50 - Math.cos(rad) * 50).toFixed(1), y1 = (50 - Math.sin(rad) * 50).toFixed(1);
    const x2 = (50 + Math.cos(rad) * 50).toFixed(1), y2 = (50 + Math.sin(rad) * 50).toFixed(1);
    const stops = parts.map((p, i) => {
      const m = p.match(/^(.*?)(?:\s+([\d.]+)%)?$/);
      const off = m[2] !== undefined ? m[2] : (i / Math.max(parts.length - 1, 1) * 100).toFixed(0);
      return `<stop offset="${off}%" stop-color="${esc(m[1].trim())}"/>`;
    }).join('');
    const id = 'g' + (gi++);
    defs += `<linearGradient id="${id}" x1="${x1}%" y1="${y1}%" x2="${x2}%" y2="${y2}%">${stops}</linearGradient>`;
    return `url(#${id})`;
  };
  const op = s => s.op != null ? ` opacity="${s.op}"` : '';
  const body = data.shapes.map(s => s.t === 'rect'
    ? `<rect x="${s.x}" y="${s.y}" width="${s.w}" height="${s.h}"${s.r?` rx="${s.r}"`:''} fill="${fillOf(s)}"${s.stroke?` stroke="${s.stroke}" stroke-width="${s.sw}"`:''}${op(s)}/>`
    : `<text x="${s.x}" y="${s.y}" fill="${s.fill}" font-size="${s.fs}" font-weight="${s.fw}" font-family="Inter, sans-serif"${op(s)}>${esc(s.s)}</text>`
  ).join('');
  return `<svg xmlns="http://www.w3.org/2000/svg" width="${data.W}" height="${data.H}" viewBox="0 0 ${data.W} ${data.H}" role="img" aria-labelledby="t d"><title id="t">${esc(title)}</title><desc id="d">${esc(desc)}</desc>${defs?`<defs>${defs}</defs>`:''}${body}</svg>`;
};
```

- [ ] **Step 4: Audit what the extractor cannot express**

```js
const thumb = [...document.querySelectorAll('.work-card[data-industry] .work-thumb')][1];
const missed = { opacity: [], blend: [], repeating: [], transform: [], shadow: [] };
thumb.querySelectorAll('*').forEach(el => {
  const cs = getComputedStyle(el);
  const tag = el.tagName.toLowerCase() + (el.className ? '.' + String(el.className).split(' ')[0] : '');
  if (+cs.opacity < 1 && +cs.opacity > 0) missed.opacity.push(`${tag}=${cs.opacity}`);
  if (cs.mixBlendMode !== 'normal') missed.blend.push(`${tag}=${cs.mixBlendMode}`);
  if (cs.backgroundImage.includes('repeating')) missed.repeating.push(tag);
  if (cs.transform !== 'none') missed.transform.push(tag);
  if (cs.boxShadow !== 'none') missed.shadow.push(tag);
});
JSON.stringify(missed, null, 1)
```

Expected for Iron Republic: one `opacity` entry (now handled by Step 2) and one `repeating` entry. `blend`, `transform` and `shadow` should be empty.

- [ ] **Step 2: Write `assets/site-ui.js`**

```js
/* ============================================================
   Shared UI behaviour for the portfolio pages.

   Three self-guarding blocks. Each returns early when its
   elements are absent, so one file serves every page.

   NOT for the demo pages. Those are simulated client sites and
   carry their own, different reveal implementations.
   ============================================================ */
(() => {
  'use strict';

  /* ---- Scroll reveal with stagger ---- */
  const reveals = document.querySelectorAll('.reveal');
  if (reveals.length) {
    if ('IntersectionObserver' in window) {
      const obs = new IntersectionObserver((entries) => {
        entries.forEach(e => {
          if (!e.isIntersecting) return;
          const siblings = [...(e.target.parentElement?.children ?? [])];
          e.target.style.transitionDelay = (siblings.indexOf(e.target) % 3) * 90 + 'ms';
          e.target.classList.add('visible');
          setTimeout(() => { e.target.style.transitionDelay = ''; }, 700);
          obs.unobserve(e.target);
        });
      }, { threshold: 0.08, rootMargin: '0px 0px -40px 0px' });
      reveals.forEach(el => obs.observe(el));
    } else {
      reveals.forEach(el => el.classList.add('visible'));
    }
  }

  /* ---- Mobile nav drawer ---- */
  const toggle = document.querySelector('.nav-toggle');
  const panel  = document.getElementById('mobile-panel');
  if (toggle && panel) {
    const shut = () => {
      panel.classList.remove('open');
      toggle.setAttribute('aria-expanded', 'false');
      toggle.setAttribute('aria-label', 'Open navigation');
    };
    toggle.addEventListener('click', () => {
      const open = panel.classList.toggle('open');
      toggle.setAttribute('aria-expanded', String(open));
      toggle.setAttribute('aria-label', open ? 'Close navigation' : 'Open navigation');
    });
    panel.querySelectorAll('a[href^="#"]').forEach(a => a.addEventListener('click', shut));
    document.addEventListener('click', e => {
      if (panel.classList.contains('open') && !panel.contains(e.target) && !toggle.contains(e.target)) shut();
    });
  }

  /* ---- Work filter: one axis, industry ---- */
  const filterBtns = document.querySelectorAll('.filter-btn');
  const cards      = document.querySelectorAll('.work-card[data-industry]');
  if (filterBtns.length && cards.length) {
    const en = (document.documentElement.lang || 'th').toLowerCase().startsWith('en');
    const COPY = en
      ? { none: 'No projects in this category yet', some: n => `Showing ${n} projects` }
      : { none: 'ยังไม่มีผลงานในหมวดนี้',            some: n => `แสดง ${n} ผลงาน` };

    const emptyState   = document.getElementById('works-empty');
    const filterStatus = document.getElementById('filter-status');
    const chip         = document.getElementById('active-filter-chip');
    const chipLabel    = document.getElementById('active-filter-label');
    const chipClear    = document.getElementById('active-filter-clear');

    const industriesOf = c => (c.dataset.industry || '').trim().split(/\s+/).filter(Boolean);
    const matches = (c, f) => f === 'all' || industriesOf(c).includes(f);

    filterBtns.forEach(btn => {
      const countEl = btn.querySelector('.filter-count');
      if (!countEl) return;
      let n = 0;
      cards.forEach(c => { if (matches(c, btn.dataset.filter)) n++; });
      countEl.textContent = String(n);
    });

    function applyFilter(filter, label) {
      let visible = 0;
      filterBtns.forEach(b => {
        const on = b.dataset.filter === filter;
        b.classList.toggle('active', on);
        b.setAttribute('aria-pressed', on ? 'true' : 'false');
      });
      cards.forEach(c => {
        if (matches(c, filter)) { delete c.dataset.hidden; visible++; }
        else c.dataset.hidden = '';
      });
      if (chip) {
        const show = filter !== 'all';
        chip.hidden = !show;
        if (show && chipLabel) chipLabel.textContent = label;
      }
      if (emptyState) emptyState.hidden = visible > 0;
      if (filterStatus) filterStatus.textContent = visible === 0 ? COPY.none : COPY.some(visible);
    }

    filterBtns.forEach(btn =>
      btn.addEventListener('click', () => applyFilter(btn.dataset.filter, btn.dataset.label || '')));

    chipClear?.addEventListener('click', () => {
      applyFilter('all', '');
      document.querySelector('.filter-btn[data-filter="all"]')?.focus();
    });
  }
})();
```

The status strings now come from `document.documentElement.lang`, which is what lets the Thai and English filter blocks merge into one.

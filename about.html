ทักษะและเครื่องมือ

  • เขียนหน้าเว็บด้วย HTML, CSS และ JavaScript ตรงๆ — งานส่วนใหญ่ในพอร์ตนี้ไม่ได้ใช้ไลบรารีภายนอกเลย เพราะทำให้เว็บเบาและโหลดเร็วกว่า
  • ทำให้แสดงผลได้ดีตั้งแต่จอมือถือ 375px ขึ้นไปจนถึงจอเดสก์ท็อป
  • วางโครงสร้างหัวข้อ meta description canonical และ sitemap ให้ Google เก็บข้อมูลได้ครบ
  • ดูแลเรื่อง accessibility — ลำดับหัวข้อ ป้ายกำกับปุ่ม และคอนทราสต์สีระดับ WCAG AA
  • ออกแบบใน Figma ก่อนลงมือเขียน และใช้ React กับ Vite เมื่อโปรเจกต์ต้องการจริงๆ (เช่น HabitQuest)
